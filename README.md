# Aircraft Predictive Maintenance & Reliability Analytics

## Overview

This project predicts aircraft engine Remaining Useful Life (RUL) using the NASA CMAPSS dataset.

## Features

- Predictive Maintenance
- Remaining Useful Life Prediction
- Failure Risk Assessment
- Reliability Analytics
- Maintenance Scheduling
- Power BI Dashboard

## Dataset

NASA CMAPSS Turbofan Engine Dataset

## Models

- Random Forest
- XGBoost

## Results

| Model | MAE | RMSE | R² |
|---------|---------|---------|---------|
| Random Forest | 11.96 | 15.87 | 0.851 |
| XGBoost | 10.24 | 13.94 | 0.885 |

- Fleet Overview
